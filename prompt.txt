PROJECT NAME:

SAT Practice Learning System


==================================================

PROJECT OBJECTIVE:

Create a beginner-friendly SAT preparation platform.

The application allows students to create an account, login, practice SAT Math and Reading questions, complete tests, receive scores, and track their progress.


==================================================

TARGET USERS:

Students preparing for SAT exams.
